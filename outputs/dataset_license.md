# Dataset source and license record

Source: Alessio Corrado, Animals-10, Kaggle dataset version 2, last updated 12 December 2019.

- Dataset: https://www.kaggle.com/datasets/alessiocorrado99/animals10
- Metadata endpoint: https://www.kaggle.com/api/v1/datasets/view/alessiocorrado99/animals10
- Accessed: 19 November 2026. Metadata saved in `outputs/dataset_metadata.json`.
- Kaggle metadata and the official download client identify the dataset license as GPL-2.0.
- License text: https://www.gnu.org/licenses/old-licenses/gpl-2.0.html

The GPL requires preserving license and copyright notices when redistributing covered material. The dataset description says its images were collected from Google Images and does not provide individual image authors or licenses. The dataset-level license does not establish that the uploader held every photograph's rights. This project therefore does not redistribute the raw or resized photographs, image-bearing outputs, or the university report publicly. Local educational figures retain this dataset credit. Public notebooks are cleared of all execution outputs, while numerical experiment records and image-free charts may be published.

The project source and independently produced numerical outputs are separate from the dataset. The three small fitted parameter files (about 469 KiB in total) are included for reproducible saved inference. They contain numerical parameters, not the dataset photographs. Dataset and individual-image attribution limits remain documented; inclusion of fitted parameters is not a claim of individual image clearance.
